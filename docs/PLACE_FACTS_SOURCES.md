# 장소 사실 수집원 — 선정 기록

저장소: <https://github.com/orialthq/trun-on>

`/v1/place-facts` 파이프라인이 어디서 데이터를 가져오는지, 그리고 후보였다가
접은 것들을 왜 접었는지의 기록입니다. 축 설계와 구세대(모델 웹서치) 측정은
[PLACE_ENRICHMENT.md](PLACE_ENRICHMENT.md)에 있습니다. 여기 결론은
2026-08-09 ~ 08-12에 실제 호출과 약관 원문 확인으로 재본 것이고, 다시 재려면
같은 비용이 드니 결론과 함께 남깁니다.

## 채택 — 현재 구성

| 소스 | 용도 | 비용 |
| --- | --- | --- |
| OpenAI `gpt-5.6-luna` | 스크린샷 비전 · 증거 문장 추출. **웹서치 툴은 안 씀** | 추출 1회/곳 |
| Serper `/maps` | 가게 확정 — fid·주소·좌표·가격범위·영업시간·예약링크 | $0.001/쿼리 |
| Serper `/reviews` | 구글 리뷰 20개. 웨이팅 근거의 주 서식지 — 6/10곳 (웹 스니펫은 2/10) | 〃 |
| Serper `/search` | 테이블링·캐치테이블·다이닝코드 스니펫. `site:` OR 로 쿼리 1개에 편승 | 〃 |
| Serper `/videos` | 유튜브 제목·설명 5개. 유명한 곳의 교차 확인용 | 〃 |

곳당 신규 Serper 4쿼리 $0.004 + 추출 1회 ≈ **$0.007 · ~25초**. 반복 조회
**$0 · ~2초** (저장소 TTL: 사실 7일, 가게 확정 30일).

Serper를 고른 이유는 두 가지입니다. 모델 웹서치 경로 대비 곳당 12배 싸고,
**같은 쿼리가 같은 행을 돌려줍니다.** 결과가 결정적이어야 증거 저장소가
실행마다 뒤집히지 않고 누적됩니다.

실전 확인 (2026-08-12, 폰): 구글에 가격 필드가 없는 골목 가게(봉천다찌)가
리뷰 문장 속 금액 파싱 폴백으로 `가격대 2~5만원`을 얻었습니다. 웨이팅·주차는
증거가 없어 비었고, 그게 정답입니다.

### 등재는 웨이팅의 근거가 아니다 (2026-08-13 검증)

테이블링 등재만으로 `웨이팅 있음`을 확정하던 규칙(`waitingFromListing`)을
검증 후 **제거**했습니다. 테이블링은 웨이팅 외에 예약·포장·빈자리선점을 팔고
예약 전용 B2B 상품(`b2b.tabling.co.kr/reservation`)까지 있어서, 등재는
"고객사"라는 뜻이지 "줄이 있다"가 아닙니다. 반례 실물: **쉐박** — 등재된
베이커리인데 태그가 `예약가능·포장·배달`뿐, 웨이팅 없음. 테이블링 가게
페이지는 `웨이팅`과 `예약가능`을 태그로 따로 구분합니다(금돼지식당은 둘 다).
저장소 실측으로도 이 규칙의 발동은 0건이었습니다 — 구글 booking 링크는
전부 `catchtable.net`.

원칙: **등재가 증명하는 건 예약입니다.** 웨이팅은 웨이팅 전용 표면(테이블링
`웨이팅` 태그, 캐치테이블 웨이팅 기획전, 다이닝코드 `웨이팅 방법` 필드)이나
문장(`waitingFromNotices` — 원격줄서기 운영 공지)만 근거가 됩니다.

2026-08-14 추가 실측: 테이블링 place 페이지는 **미입점 가게도** 만듭니다 —
모에루 문래본점 페이지에 "아직 테이블링 입점되지 않음" 표기. 등재는 고객사
여부조차 증명하지 않는 디렉토리이므로, 페이지 존재로는 아무것도 확정할 수
없습니다.

## 남은 카드

- **DataForSEO popular times** — 혼잡 시간대를 웨이팅 축의 교차 근거로. 키 보관 중
- **다이닝코드 "웨이팅 방법" 필드** — 필드 존재 자체를 근거로 모델 판단 없이
  `대기 있음` 확정 (재현성 100%). 페이지 존재가 곧 사실인 부류
- **지오펜스 방문 확인** — 나중. 네이버는 종결

파이프라인 대기열 (2026-08-12 기준): 추출 2회 합집합(재현성, 1순위) ·
Serper 재시도(빈 카드 방지) · 캡션 배선(화면 속 "웨이팅 30분" — 비용 0) · 팁 UI.

## 키 위치

맥 키체인 `ori-beauty-{openai,serper,deepseek,kakao}` —
[dev-keychain.sh](../server/scripts/dev-keychain.sh)가 읽어서 서버에 주입합니다.
`ori-beauty-dataforseo`는 보관만. 새 키를 넣을 때 `security add-generic-password`의
대화식 `-w` 프롬프트는 128자에서 잘리니 인자로 넘겨야 합니다.
