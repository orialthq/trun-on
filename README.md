# Ori Beauty

> 저장한 뷰티 콘텐츠를, 출처가 남는 정리로.

Ori Beauty는 SNS에서 발견한 스킨케어 콘텐츠를 공유하면 원본을 먼저
보존하고, 제품·주장·맥락을 근거와 함께 분석해 같은 제품별로 정리하는
Android-first 앱입니다.

**현재 상태:** Pre-alpha · Android first · Flutter

## 현재 제품 범위

이번 베이스라인은 구매 결정을 대신하지 않습니다. 먼저 어려운 문제인
`input → 분석 → 확인·수정 → 정리`를 정확하게 해결합니다.

```text
SNS에서 URL·텍스트 공유
→ 원본과 수집 시점 보존
→ 제품 언급·주장·명시적 광고 표시 추출
→ 불확실한 결과 확인·수정
→ 같은 제품을 다룬 콘텐츠끼리 정리
```

스크린샷·OCR은 이 흐름의 다음 입력 형식이며 아직 지원하지 않습니다.

사용자가 결과 화면에서 확인할 수 있어야 하는 것은 다음 다섯 가지입니다.

1. 무엇을 입력했는가
2. 어떤 제품이 언급됐는가
3. 콘텐츠가 정확히 무엇을 말했는가
4. 각 분석 결과가 원본 어디에서 나왔는가
5. 같은 제품을 다룬 콘텐츠가 올바르게 묶였는가

## 제품 원칙

1. **분석보다 보존** — 분석이 실패해도 사용자가 공유한 원본은 남습니다.
2. **결론보다 근거** — 요약과 태그는 항상 확인 가능한 원본 근거를
   가집니다.
3. **확정 대신 불확실성** — 모르는 값과 애매한 제품을 임의로 확정하지
   않습니다.
4. **자동화보다 사용자 통제** — 제품 식별, 콘텐츠 묶음, 분석 결과를
   사용자가 수정할 수 있습니다.
5. **잘못 합치지 않기** — 같은 제품을 따로 두는 것보다 다른 제품을
   하나로 합치는 오류를 더 위험하게 취급합니다.
6. **주장과 사실 구분** — 콘텐츠의 표현을 검증된 제품 효능처럼
   제시하지 않습니다.

## 입력 계약 요약

한 번의 공유는 하나의 `RawCapture`로 저장합니다.

- Android 공유 메뉴의 URL·텍스트
- 앱 안에서 붙여넣은 URL·텍스트
- 안전한 로컬 복사가 구현된 뒤 추가할 스크린샷
- 선택적인 사용자 메모

원본 URL과 정규화된 URL, 공유 시각, 출처 앱, MIME 형식, 중복 판별용
semantic fingerprint를 함께 기록합니다. 현재 fingerprint는 분석 계약에
기록만 하며, 서로 다른 공유 이벤트의 콘텐츠 중복 제거에는 아직
사용하지 않습니다.

Instagram, TikTok 등 접근이 제한된 URL은 저장할 수 있지만 URL만으로
분석 성공을 보장하지 않습니다. 이 경우 `자료 부족`으로 표시하고
텍스트나 스크린샷 추가를 요청합니다. 로그인 우회, 비공개 콘텐츠
수집, 영상 다운로드는 하지 않습니다.

## 정리 결과

앱은 두 가지 보관함을 제공합니다.

- **콘텐츠 보관함:** 원본, 플랫폼, 수집 시각, 분석 상태, 추출된 제품과
  주제
- **제품 보관함:** 같은 제품으로 확인된 콘텐츠, 반복 언급된 주제,
  출처별 주장과 명시적 광고·협찬 표시

예를 들어 `가벼운 사용감 · 3개 콘텐츠에서 언급`을 보여줄 수는 있지만,
`이 제품이 가장 좋다`고 결론내리지 않습니다. 각 언급을 누르면 근거가
된 원문 또는 스크린샷 위치를 확인할 수 있어야 합니다.

## 이번 베이스라인에서 하지 않을 것

- 구매 후보·보류·제외 결정
- 제품 간 비교 승자 또는 추천 순위
- 피부 타입·현재 루틴 기반 적합성·중복 판정
- 가격·최저가·재고·구매 링크·알림
- 성분 안전성·효능 검증·의학적 판단
- 광고 여부 추론 또는 크리에이터 신뢰 점수
- SNS 저장 목록 전체 자동 가져오기
- 플랫폼 제한을 우회하는 크롤링이나 영상 다운로드
- 커뮤니티, 댓글, 크리에이터 팔로우
- Android 베이스라인 검증 전 iOS 동시 출시

## 로컬 실행

필수 환경:

- Flutter `3.44.8`
- Dart `3.12.2`
- Android Studio와 Android SDK
- iOS 프로젝트를 열려면 Xcode

```bash
flutter pub get
flutter analyze --fatal-infos
flutter test
flutter run
```

Android 공유 수신을 터미널에서 확인하려면 디버그 앱을 설치한 후:

```bash
adb shell am start \
  -a android.intent.action.SEND \
  -t text/plain \
  --es android.intent.extra.TEXT "https://example.com/skincare" \
  com.orialthq.ori_beauty/.MainActivity
```

## 현재 구현된 프로토타입

- Android `text/plain` 공유를 앱 시작 전에도 보존하는 pending queue
- 원본·분석·검토·제품 묶음의 versioned 로컬 snapshot
- snapshot 저장 성공 뒤에만 pending 공유를 acknowledge하는 순서
- 원본과 정규화 URL 분리, 추적 query 제거, 플랫폼 식별
- 가상 제품 규칙과 일반 뷰티 제품명 휴리스틱을 이용한 단일 제품 후보
- 제품 필드별 불확실성 band, 주제별 원문 인용, 명시적 광고 표시 추출
- 브랜드·제품명·카테고리·용량 확인·수정과 `제품 특정 못함` 처리
- 사용자가 확인한 완전 일치 제품만 같은 제품 묶음에 연결
- 콘텐츠 보관함과 제품 보관함

로컬 실행에는 기능을 바로 확인할 수 있는 가상 demo fixture 5개가
포함됩니다. 현재 분석기는 네트워크나 SNS 본문을 조회하지 않는
deterministic rule prototype입니다.

아직 한 입력에서 여러 제품을 나누는 기능, 스크린샷·OCR, 제품 필드
근거 탐색, 묶음 수동 합치기·분리, 삭제·되돌리기, 서로 다른 이벤트의
내용 중복 제거는 구현 전입니다. 상세 진행 상태는
[베이스라인 로드맵](docs/ROADMAP.md)에 표시합니다.

## 첫 번째 완료 조건

> 애매한 값은 확인 필요로 남고, 사용자가 수정·분리·병합·삭제할 수

## 안전 고지

Ori Beauty는 사용자가 공유한 뷰티 콘텐츠를 정리하는 정보 도구이며
의료 서비스가 아닙니다. 콘텐츠 작성자의 표현은 검증된 효능이나 안전성
판정이 아닙니다. 피부 질환, 알레르기 또는 이상 반응과 관련된 판단은
의료 전문가와 상의해야 합니다.

## 기여 및 라이선스

아직 초기 단계라 데이터 모델과 API가 빠르게 바뀔 수 있습니다. 버그와
제품 제안은 GitHub Issues로 남겨주세요. 개인정보가 포함된 SNS
스크린샷이나 계정 정보는 공개 이슈에 첨부하지 마세요.

이 저장소에는 아직 오픈소스 라이선스가 부여되지 않았습니다. 공개 열람은
가능하지만 별도의 허가 없이 복제·배포·상업적으로 이용할 수 없습니다.
