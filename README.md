# Ori Beauty

> 저장한 스킨케어, 이제 결정하세요.

Ori Beauty는 SNS에서 발견한 스킨케어 콘텐츠를 공유하면 제품을 찾아
묶고, 근거를 비교해 `구매 후보 · 보류 · 제외` 결정을 돕는 앱입니다.

**현재 상태:** Pre-alpha · Android first · Flutter

## 핵심 흐름

```text
SNS에서 콘텐츠 공유
→ 제품 후보 확인
→ 같은 제품을 다룬 콘텐츠 통합
→ 주장·출처·차이 비교
→ 구매 후보 / 보류 / 제외
```

목표는 저장물을 더 많이 쌓는 것이 아니라, 사용자가 더 적은 시간에
납득할 수 있는 결정을 내리게 하는 것입니다.

## 지금 실행할 수 있는 것

첫 번째 vertical slice가 로컬 데모 데이터로 동작합니다.

- 수집함에서 분석·확인·결정 상태 확인
- 제품 상세에서 현재 루틴 중복과 판단 근거 확인
- 최대 3개 제품 비교
- 구매 후보·보류·제외 결정과 실행 취소
- 사용자 피부 기준과 현재 루틴 확인
- Android 공유 메뉴에서 `text/plain` URL 수신
- 앱 cold/warm start에서 공유 URL을 잃지 않는 로컬 pending queue

데모에 표시되는 브랜드와 제품은 모두 가상입니다. 실제 효능이나 구매
권고를 의미하지 않습니다.

## 로컬 실행

필수 환경:

- Flutter `3.44.8`
- Dart `3.12.2`
- Android Studio와 Android SDK
- iOS 프로젝트를 열려면 Xcode

```bash
flutter pub get
flutter analyze --fatal-infos
flutter test
flutter run
```

Android 공유 수신을 터미널에서 확인하려면 디버그 앱을 설치한 후:

```bash
adb shell am start \
  -a android.intent.action.SEND \
  -t text/plain \
  --es android.intent.extra.TEXT "https://example.com/skincare" \
  com.orialthq.ori_beauty/.MainActivity
```

## MVP에서 제공할 것

- Android 공유 메뉴를 통한 URL·텍스트 수집
- 브랜드·제품명·용량 등 제품 후보 추출
- 불확실한 결과에 대한 사용자 확인과 수정
- 같은 제품을 다룬 여러 출처 통합
- 출처별 주장과 명시적인 광고·협찬 표시 정리
- 최대 3개 제품 비교
- 구매 후보·보류·제외 상태와 결정 이유 기록
- 분석 실패 시 원본을 잃지 않는 수동 확인 흐름

## 이번 MVP에서 하지 않을 것

- SNS 저장 목록 전체 자동 가져오기
- 플랫폼 제한을 우회하는 크롤링이나 영상 다운로드
- 피부 사진 기반 진단
- 질환·치료·성분 안전성에 대한 의학적 판정
- 자동 구매 또는 수수료 기반 제품 순위
- 실시간 최저가·재고·가격 하락 알림
- 색조·헤어·향수·시술 카테고리
- 커뮤니티, 댓글, 크리에이터 팔로우
- Android 검증 전 iOS 동시 출시

## 제품 원칙

1. **수집보다 결정** — 저장 개수가 아닌 결정 완료를 최적화합니다.
2. **확신보다 근거** — 결과에 원본 출처와 불확실성을 함께 보여줍니다.
3. **자동화보다 사용자 통제** — 제품 매칭과 결정은 수정할 수 있습니다.
4. **주장과 사실의 구분** — 콘텐츠 표현을 검증된 효능처럼 제시하지 않습니다.
5. **수익보다 신뢰** — 제휴 수수료가 비교 결과나 순위를 바꾸지 않습니다.
6. **최소한의 데이터** — 사용자가 직접 공유한 정보만 필요한 범위에서 처리합니다.

## 첫 번째 마일스톤

> 실제 Android 기기에서 SNS 콘텐츠 3개를 공유하고, 제품을 확인·비교한
> 뒤 최소 1개를 구매 후보·보류·제외로 결정할 수 있다.

세부 제품 범위는 [제품 정의](docs/PRODUCT.md), 구현 구조는
[아키텍처](docs/ARCHITECTURE.md), 진행 계획은
[MVP 로드맵](docs/ROADMAP.md)을 참고하세요.

## 안전 고지

Ori Beauty는 스킨케어 구매 결정을 돕는 정보 도구이며 의료 서비스가
아닙니다. 피부 질환, 알레르기 또는 이상 반응과 관련된 판단은 의료
전문가와 상의해야 합니다.

## 기여 및 라이선스

아직 초기 단계라 데이터 모델과 API가 빠르게 바뀔 수 있습니다. 버그와
제품 제안은 GitHub Issues로 남겨주세요. 개인정보가 포함된 SNS
스크린샷이나 계정 정보는 공개 이슈에 첨부하지 마세요.

이 저장소에는 아직 오픈소스 라이선스가 부여되지 않았습니다. 공개 열람은
가능하지만 별도의 허가 없이 복제·배포·상업적으로 이용할 수 없습니다.
